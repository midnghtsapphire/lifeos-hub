# Security Policy

## Supported scope

This repository is under active development; report potential vulnerabilities for current default branch behavior.

## Reporting a vulnerability

Please open a private security report through GitHub Security Advisories for this repository.

Include:
- Reproduction steps
- Impact summary
- Suggested remediation if available

## Security baseline

- Do not commit secrets or `.env` files.
- Keep Supabase credentials in environment variables only.
- Validate authentication and protected-route behavior after deployments.
